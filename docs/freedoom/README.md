# Freedoom, and what of it is here

The character art in `src/game/freedoomart.ts` is generated from
[Freedoom](https://freedoom.github.io/) 0.13.0 by `scripts/bakeart.ts`. It is a
derivative of Freedoom's own artwork, which is released under the three-clause
BSD licence reproduced verbatim in `COPYING.txt`, with the contributors it
refers to listed in `CREDITS.txt`. Both files are copied from the Freedoom
distribution and are not edited.

The licence asks three things of anyone redistributing this, and all three are
met here. The notice and the disclaimer travel with the work, which is what
these files are for. They are reachable from the README, which is the
documentation the licence means. And nothing in this project uses the Freedoom
name to suggest that the Freedoom project endorses it — it does not know this
exists.

No Freedoom data file is redistributed. The WAD is read once, at a desk, to
generate the source; it is not committed, not bundled, and not needed to play.

Nothing here is from a commercial game. Freedoom is an independent work that
happens to be compatible with one.
